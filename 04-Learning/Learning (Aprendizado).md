Até agora, implementei apenas algoritmos com regras definidas e recursões para conseguir fazer inferencias para um determinada objetivo.

Agora, vamos ver mais sobre learning que é o processo para conseguir fazer inferencias passando dados para nossa IA conseguir aprender com esses dados e conseguir descobrir padrões, assim fazendo inferencias baseadas na precisão matemática.

### Exemplo
Caso eu queira descobrir se amanha vai chover, eu poderia pegar os dados dos dias anteriores, como pressão atmosférica, umidade passar a informação se naquele dia choveu ou não, etc.
Com isso a nossa IA consegue fazer previsões sobre se vai chover ou não no dia seguinte, através de cálculos matemáticos sobre os dados que nos passamos para ela, assim ela achará um padrão que acontece durante os dias que chovem e vai determinar se tal dia vai chover.
