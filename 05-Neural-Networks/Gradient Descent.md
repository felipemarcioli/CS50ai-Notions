Gradient Descent é um método matematico para encontrar o menor valor possivel determinadas variaveis.

Pense que voce está no topo de uma montanha e quer chegar la em baixo, tentando minimizar os erros.

Para isso você analisa se o terreno esta descendo para direita ou para a esquerda. Com isso voce da passos para qual lado está descendo até eventualmente chegar no ponto mais baixo.

![Neural Network - Image example 3](../PNGs/05-Neural%20Network.png/Neural%20Network%20-%20Image%20example%203.png)

Isso tem haver com **Inteligencia Artificial** porque no [Backpropagation](./Backpropagation.md) precisamos encontrar o menor valor dos **pesos** para minimizarmos o erro.

---
## Formula
$$
\theta := \theta - \alpha \nabla J(\theta)
$$
