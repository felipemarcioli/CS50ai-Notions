Optimization é a estratégia para otimizar os problemas com algoritmo, suponha que temos uma bairro com quatro casas e queremos construir 2 hospitais nesse bairro, como poderiamos fazer para otimizar a localização dos hospitais de forma que fique perto das 4 casas? Nós usamos o **optimization** para esse tipo de problema

![Optimization Image 0](../PNGs/03-Optimization.png/Optimization%20Image%200.png)

Somando a distancia das casas com até o hospital essa distancia é igual a 17, sendo representada pelo **cost**. O objetivo com o optimization, é diminuir esse cost o maximo possivel.

De forma mais abstrata, nós podemos ilustrar os melhores states de forma global por barras, assim conseguimos um grafico onde cada state e o seu cost é representado por barras

![Optimization Image 1](../PNGs/03-Optimization.png/Optimization%20Image%201.png)
